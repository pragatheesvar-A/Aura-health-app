# Aura — AI Health Screening Platform

**Aura** is a sophisticated, privacy-first health diagnostic tool that leverages on-device AI to provide instant health insights. Designed for accessibility and security, Aura works 100% offline to screen for common health conditions.

## 🚀 Key Features
- **📸 AI Computer Vision:** Detects physiological markers for Anemia (Pale conjunctiva/lips) and Dehydration (Skin turgor/nail refill) using on-device CNN models.
- **🎤 Acoustic Waveform Analysis:** Deep-learning pipeline utilizing MFCC features to analyze cough and breathing patterns for respiratory concerns.
- **🌐 100% Offline Engine:** All AI inference happens locally on the device, ensuring ultra-low latency and total user privacy.
- **🧠 Intelligent Risk Engine:** A multi-factor diagnostic logic that combines visual scans, audio analysis, and user symptoms to generate a comprehensive Health Score.
- **💎 High-Fidelity UI:** A futuristic "Cyber-Medical" aesthetic featuring glassmorphism, pulse animations, and real-time scanner grids.

## 🛠️ Technology Stack
- **Frontend:** React.js
- **Styling:** Vanilla CSS3 with custom animations
- **AI/ML:** TFLite (On-device Inference), MobileNetV2 (Image Analysis), MFCC Pipeline (Acoustic Analysis)
- **Typography:** [Syne](https://fonts.google.com/specimen/Syne) & [Space Mono](https://fonts.google.com/specimen/Space+Mono)

## 📱 How it Works
1. **Visual Scan:** Position your lips, eyelids, or skin within the scanner frame.
2. **Audio Check:** Record a few natural breaths and coughs.
3. **Symptom Log:** Input current symptoms via the digital diary.
4. **AI Report:** Receive an instant, prioritized risk assessment and health advice.

## 🔒 Privacy & Security
Aura is built with a "Privacy by Design" philosophy. Since all analysis is performed on-device, your medical data never leaves your smartphone. No internet connection is required for diagnostic features.
